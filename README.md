Ответы на вопросы

1. Чем useCallback отличается от useMemo?

useCallback мемоизирует функцию.
useMemo мемоизирует результат вычисления.
useCallback используют для колбэков и обработчиков событий.
useMemo используют для тяжелых вычислений.


2. Почему React.memo не помогает без useCallback?

Потому что при каждом ререндере создаётся новая функция.
React.memo сравнивает props по ссылке.
Новая функция = новый props = повторный ререндер.


3. Когда использовать useReducer вместо useState?

Когда состояние сложное:
- много полей
- много действий
- сложная логика обновления

useReducer делает код чище и удобнее.


4. Что такое useRef?

useRef хранит значение между ререндерами.
Изменение ref.current не вызывает новый ререндер.


5. Зачем useContext нужен Provider?

Provider передаёт данные через дерево компонентов.
Без Provider useContext получит defaultValue.

6. Разница между controlled и uncontrolled input?

Controlled:
React полностью управляет input через state.

Uncontrolled:
значение хранится внутри DOM.

React Hook Form использует uncontrolled подход для меньшего количества ререндеров.



7. Почему zodResolver — не серверная валидация?

Потому что это проверка только в браузере.
Пользователь может обойти frontend.
Поэтому данные ОБЯЗАТЕЛЬНО валидируются ещё и на сервере.
